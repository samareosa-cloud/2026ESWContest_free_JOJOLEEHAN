## Indoor Demo Mode

실내에서는 GPS를 쓸 수 없으므로, TMAP 경로 대신 **ㄱ자 경로를 나침반 방향으로 안내**합니다.
앱 상단 **실내 시연** 카드에서 회전 방향을 고르고, 출발점에서 정면을 향한 채 **시연 시작**을 누릅니다.

| 단계 | 안내 | 다음 단계 조건 |
| --- | --- | --- |
| 1 | 직진 | 횡단 종료 (`CROSSING_END`) |
| 2 | 좌/우 회전 (정면 ±90°) | 새 방향을 2.5초 유지 |
| 3 | 직진 | 장애물 회피 후 3초 |
| 4 | 도착 | — |

- 횡단보도·장애물 처리 중에는 기존과 같이 조향을 멈추고 단계도 진행하지 않습니다.
- **다음 단계** 버튼으로 수동 진행할 수 있습니다.
- TMAP API 키 없이 동작합니다.

## iOS

```bash
flutter pub get
cd ios && pod install && cd ..
flutter run --release
```

- Xcode의 **Signing & Capabilities**에서 Team을 설정해야 합니다.
- 아이폰에서 **개발자 모드**를 켜고, 설치 후 **설정 → 일반 → VPN 및 기기 관리**에서 개발자를 신뢰합니다.
- 케이블 없이 실행하려면 `--release`로 설치합니다. 무료 계정으로 설치한 앱은 7일 후 다시 설치해야 합니다.
